# How T3 fork chooses models for delegated tasks

The main coordinator and each project coordinator can check account allowance and get a model recommendation before delegating. T3 fork considers the kind of work and how much judgment it needs. The recommendation includes a short reason. Open **Settings → Usage → Limits** for detailed meters.

Fork delegation checks the chosen account again when launching work, including reviews and tasks delegated by children. An excluded account or one that has reached an applicable limit cannot be used. Shared and model-specific limits both apply. If a model has its own allowance, the account still needs allowance in its shared windows.

You can ask for a specific model. T3 fork checks that it is available and eligible for the task. If it cannot verify an eligible choice, it reports why so you can check **Settings → Usage → Limits** or choose another eligible target. Starting a thread yourself keeps the usual model controls.
